# 상주 무양동 상가 임대

경상북도 상주시 무양동 274-3 (상주종합버스터미널 맞은편) 신축 건물 임대 안내 페이지입니다.

- `index.html` — 안내 페이지 (사진 포함, 단일 파일)
- `og.jpg` — 카카오톡/SNS 공유 시 표시되는 미리보기 이미지

## 공개 주소

https://neti84-design.github.io/imdae/

## 게시 설정 방법

저장소 **Settings → Pages** 에서
- Source: `Deploy from a branch`
- Branch: 이 브랜치 선택, 폴더는 `/ (root)`

저장 후 1~2분이면 위 주소로 누구나 접속할 수 있습니다.
