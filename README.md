# 쏙 — 흰머리 뽑기

확대된 머리카락 속에서 흰머리만 골라 쏙 뽑는 힐링 앱. 기획서: [docs/기획서.md](docs/기획서.md)

지금 버전은 기획서 11장의 **1~2단계(손맛 확인 + MVP)** 를 웹 앱(PWA)으로 만든 체험판입니다.
빌드 없이 바로 열리고, 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 실행
- `index.html`을 브라우저로 열면 됩니다 (파일로 열어도 동작).
- 휴대폰 테스트: GitHub Pages 등에 올린 뒤 휴대폰 브라우저로 접속 → 홈 화면에 추가.
  - 진동은 안드로이드 크롬에서 제대로 느껴집니다. 아이폰 사파리는 진동 API가 없어 뽑을 때만 짧은 시스템 햅틱(iOS 18+)이 납니다.

## 조작
처음 시작하면 **움직이는 그림 사용법(5장)** 이 뜨고, 이어서 첫 판은 화면 아래 안내(① 쓸기 → ② 꾹 누르기 → ③ 당기기)를 따라 하게 됩니다. 플레이 중 **?** 버튼이나 홈의 "손가락 사용법 보기"로 다시 볼 수 있습니다.

- 손가락으로 쓸기: 머리카락을 **뒤적이기** (찰랑이며 갈라졌다가 천천히 제자리로)
- 여러 손가락을 시간차로 대면 각 손가락이 머리를 가른 채 붙잡고, 다른 손가락으로 흰머리를 꾹 눌러 뽑기
- 두 손가락을 동시에: 이동·확대 · 두 번 탭: 확대/축소 · (PC) 휠 확대, 오른쪽 버튼/Shift 드래그로 이동
- 흰머리를 **꾹 누르거나, 뒤적이다 흰머리 위에서 멈추면** 핀셋으로 집힘 → 바깥쪽으로 당기면 45~70px 지점에서 "톡"
- 일부 흰머리는 검은 머리 밑에 숨어 있어서 뒤적여야 보임 (흰머리는 뻣뻣해서 덜 밀림)
- 상단 미리보기에서 머리 스타일 선택: 가르마 · 옆가르마 · 가마 · 긴 생머리 · 곱슬 (∧ 버튼으로 접기)
- 천천히 당기면 뿌리째, 빠르게 당기면 끊길 확률이 올라감 (끊기면 짧게 남은 것을 다시 뽑기)
- 검은 머리를 집으면 "앗"만 뜨고 벌점 없음

## 구현된 것 (MVP)
| 기획 | 상태 |
|---|---|
| 머리 화면 (스타일 5종, 검은 머리 750~1200, 흰머리 8~20, 베지어 곡선) | ✅ |
| 찰랑이는 머리카락 뒤적이기, 숨은 흰머리 | ✅ |
| 확대·이동, 집기·당기기·뽑기, 뿌리째/끊김/앗 | ✅ |
| 햅틱: 집기 1회, 장력 따라 점점 강하게, "톡", 뿌리째 여운 | ✅ |
| 소리 ("틱", 기본 꺼짐) | ✅ WebAudio 합성 |
| 흰머리가 줄수록 윤기, 완료 시 반짝임 + "개운해졌어요" | ✅ |
| 뽑은 흰머리가 휴지 위에 가지런히 모임 (모근 표시) | ✅ |
| 그냥 뽑기 / 하루 한 판(날짜 시드, 연속 일수) | ✅ |
| 기록: 오늘 개수, 누적, 뿌리째 비율 | ✅ |
| 진행 중인 판 자동 저장 (멈춰도 그대로) | ✅ localStorage |
| 설정: 진동 세기, 소리, 알림 | ✅ (알림은 설정만 저장 — 실제 발송은 앱 버전에서) |
| 다른 심신안정: 뽁뽁이 · 키캡 (홈 맨 아래 버튼, 소리 항상 켜짐) | ✅ |
| 가족 머리 | ⬜ 3단계 |

## 구조
```
index.html           화면 4개 (홈 / 플레이 / 완료 / 설정)
css/style.css
js/feedback.js       진동·소리
js/styles.js         머리 스타일 5종 (뿌리 배치·결 방향·길이)
js/game.js           머리 생성·찰랑 물리·렌더링·제스처·뽑기 판정 (튜닝 값은 파일 맨 위 상수)
js/app.js            화면 전환·기록·설정·저장
js/calm.js, css/calm.css   다른 심신안정 (뽁뽁이·키캡, 소리 합성)
sw.js, manifest.webmanifest, icon.svg   PWA
```
