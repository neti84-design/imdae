# 흰머리 뽑기 앱 기획서 (가제: 쏙)

> 화장실에서 흰머리를 하나씩 뽑을 때처럼, 작은 걸 하나씩 없애면서 마음이 가라앉는 **몰입형 힐링 앱**

---

## 1. 한 줄 콘셉트
확대된 머리카락 속에서 **흰머리만 골라 쏙 뽑는** 앱. 뿌리째 뽑히는 순간의 진동과 소리, 다 뽑았을 때의 개운함이 핵심이다.

## 2. 왜 마음이 편해지나 (설계 원칙)
| 원칙 | 앱에서 구현 |
|---|---|
| 동작이 단순하게 반복된다 | 찾기 → 집기 → 당기기, 세 동작뿐 |
| 하나마다 끝이 분명하다 | 뽑힐 때 "톡" 진동과 소리 |
| 치울수록 눈에 보이게 깔끔해진다 | 흰머리가 줄수록 머리결이 윤기 나게 바뀜 |
| 실패해도 부담이 없다 | 점수·시간제한·광고 팝업 없음 (기본 모드) |
| 잠깐 하다 끄기 쉽다 | 한 판 1~3분, 언제든 멈춰도 그대로 저장 |

## 3. 타깃
- 1순위: 30~50대 직장인과 엄마. 짬 날 때(화장실, 출퇴근, 자기 전) 머리를 비우고 싶은 사람
- 2순위: ASMR이나 손장난감(뽁뽁이, 피젯) 좋아하는 사람
- 공감 포인트: "나도 흰머리 뽑으면 이상하게 마음이 편해" → 릴스·쇼츠로 퍼뜨리기 좋은 소재

## 4. 핵심 플레이 흐름
1. **머리 화면**: 위에서 내려다본 정수리(가르마)가 화면을 꽉 채운다. 검은 머리 사이에 흰머리가 섞여 있다.
2. **확대·이동**: 두 손가락으로 확대하고, 한 손가락으로 끌어서 이동한다. 가르마를 손가락으로 쓸면 머리가 갈라지면서 숨은 흰머리가 보인다.
3. **집기**: 흰머리를 길게 누르면 핀셋으로 집힌다(살짝 진동).
4. **당기기**: 바깥쪽으로 끌어당긴다. 당기는 동안 장력이 올라가고(진동이 점점 강해짐), 일정 거리를 넘으면 **"톡"** 하고 뽑힌다.
5. **결과**
   - 뿌리째 뽑힘: 하얀 모근이 보이고 진동이 "톡" 온다. 이게 제일 시원한 순간
   - 중간에 끊김: 짧게 남는다. 다시 집어서 뽑을 수 있다(실패 아닌 재도전)
   - 검은 머리를 집음: "앗" 하는 가벼운 반응만 있고 벌점은 없다
6. **완료**: 다 뽑으면 머리결이 반짝이는 연출과 함께 "개운해졌어요" 문구. 뽑은 흰머리는 옆 휴지 위에 가지런히 모여 있다(이것도 은근히 뿌듯한 포인트).

## 5. 감각 피드백 (가장 중요)
- **진동(햅틱)**
  - 집을 때: 가볍게 1회
  - 당기는 중: 장력에 따라 미세 진동이 점점 강해짐
  - 뽑힐 때: 짧고 또렷한 1회 ("톡")
  - 뿌리째일 때: "톡" 뒤에 아주 약한 여운
- **소리**: 머리카락이 "틱" 하고 빠지는 작은 소리. 사운드 켜기/끄기 지원. 기본은 진동만
- **화면**: 확대하면 머리카락 결과 두피가 사실적으로 보이되, 징그럽지 않게 부드러운 일러스트 톤

## 6. 모드
| 모드 | 설명 | MVP 포함 |
|---|---|---|
| 그냥 뽑기 | 시간제한·점수 없음. 다 뽑으면 다음 머리 | ✅ |
| 하루 한 판 | 매일 새 머리 1판. 연속 일수만 조용히 표시 | ✅ |
| 숨은 흰머리 | 가르마를 갈라야 보이는 흰머리가 섞인 고난도 | ⬜ 2차 |
| 가족 머리 | 엄마·아빠·할머니 등 캐릭터별 머리 (흰머리 양이 다름) | ⬜ 2차 |
| 다른 손장난 | 보풀 제거, 뽁뽁이, 키캡, 스티커 떼기, 귤 껍질 실 까기 | ⬜ 확장 |

## 7. 기록 (부담 없는 수준만)
- 오늘 뽑은 개수, 누적 개수
- 뿌리째 뽑은 비율 ("오늘 뿌리째 92%")
- 연속 일수는 끊겨도 아무 경고 없이 다시 1부터

## 8. 하지 않을 것
- 시간제한, 순위표, 실패 화면
- 판 중간에 뜨는 광고 (광고를 붙인다면 판이 끝난 뒤 선택형으로만)
- 푸시 알림 남발 (기본 꺼짐, 켜면 하루 1회 "오늘 머리 정리할까요?")

## 9. 화면 목록 (MVP)
1. 홈: "뽑으러 가기" 버튼 하나, 오늘 기록 한 줄
2. 플레이: 머리 화면 + 왼쪽 위 남은 흰머리 수 + 오른쪽 위 일시정지
3. 완료: 개운 연출, 뽑은 개수, "한 판 더" / "그만하기"
4. 설정: 진동 세기, 소리 켜기/끄기, 알림

## 10. 기술 메모 (클로드 코드로 만들 때)
- **추천 스택**: React Native + Expo (iOS·안드로이드 동시, 햅틱 지원)
  - 진동: `expo-haptics` (iOS는 세밀한 강도 조절 가능, 안드로이드는 `Vibration` API로 보완)
  - 그리기: `react-native-skia` (머리카락 수백 가닥을 부드럽게 그리기)
  - 제스처: `react-native-gesture-handler` + `react-native-reanimated` (집기·당기기·확대)
  - 저장: `AsyncStorage` (기록, 진행 중인 판)
- **빠른 체험판**: 먼저 HTML 한 장짜리 웹 버전으로 손맛(당기기 거리, 진동 타이밍)을 확인한 뒤 앱으로 옮기는 것을 권장. 웹에서는 `navigator.vibrate()`가 안드로이드에서만 동작함
- **머리카락 생성 규칙**
  - 머리 한 판: 검은 머리 300~600가닥, 흰머리 8~20가닥
  - 각 가닥: 시작점(두피), 곡선 조절점 2개, 굵기, 색
  - 흰머리 뽑힐 확률: 뿌리째 85%, 끊김 15% (당기는 속도가 너무 빠르면 끊김 확률 올라감 → "천천히 당기면 잘 뽑힌다"는 손맛)
- **당기기 판정**: 집은 지점에서 바깥 방향으로 약 80~120px 끌면 뽑힘. 그 전에 손을 떼면 제자리로 돌아감

## 11. 개발 순서
1. **1단계 (손맛 확인)**: 머리 화면, 흰머리 집기·당기기·뽑기, 진동. 이것만으로 "계속 하고 싶은지" 테스트
2. **2단계 (MVP)**: 완료 연출, 하루 한 판, 기록, 설정
3. **3단계 (확장)**: 숨은 흰머리, 가족 머리, 다른 손장난 모드(보풀·뽁뽁이·키캡)
4. **4단계 (출시)**: 앱 이름·아이콘, 스토어 등록, 릴스 홍보 영상
